# Music

A small but real music player built with solid-native and Solid: albums, a searchable song library, real
audio playback, and a mini player that docks above the tab bar and opens into a full-screen Now
Playing sheet.

| Screen                                                        | What it shows                                                                                                               |
| ------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------- |
| Library (`src/app/library/library.solid.tsx`)                 | Albums in a horizontal row, riding as a `<VirtualList>`'s `listHeader`, above every song, searchable from the native header |
| Album (`src/app/album/album.solid.tsx`)                       | Artwork, its tracks, and a "Play all" button - a pushed screen                                                              |
| Now playing (`src/app/now-playing/now-playing.solid.tsx`)     | Artwork, a real seek slider, play/pause/next/previous, shuffle and repeat - presented as a sheet                            |
| Mini player (`src/app/now-playing/mini-player-bar.solid.tsx`) | Docked above the tab bar on every other screen; opens Now Playing                                                           |
| Settings (`src/app/settings/settings.solid.tsx`)              | `ios:` and `android:` variants, the same pattern the wallet example's settings screen uses                                  |

The tab bar (`src/app/tabs.solid.tsx`) is a real `UITabBarController` on iOS and a bottom navigation bar on
Android. Playback itself is split into two services: `src/app/player/queue.solid.ts` (track order -
next, previous, shuffle, repeat) and `src/app/player/playback.solid.ts` (pointing a real player at
whatever the queue is on). `src/app/player/track-player.solid.ts` is the seam between them: the
production path wraps `audioPlayer()` from `@solid-native/expo/solid/player`, and the tests provide a
fake instead, since `expo-audio` is never loaded in Node.

## Run it

From the repository root, after `pnpm install`:

```sh
cd examples/music
pnpm start     # press i or a, or scan the QR code with Expo Go
pnpm test      # Solid tests in Node against a fake Fabric, no simulator
```

`solid-tests/app.test.ts` opens an album, plays it, skips a track and opens Now Playing, all
against the fake player. `solid-tests/queue.test.ts` drives the queue directly, with fake tracks
standing in for real audio, to check next, previous, shuffle and repeat in isolation.

## Assets

Every asset here is generated by this repository, not sourced from anywhere else, so there is
nothing to attribute or licence beyond the code itself:

- `assets/audio/*.m4a` - twelve short sine-wave tones, one per track, generated with `ffmpeg`
  (`assets/audio/generate.sh`). Each is two tones mixed together with a fade in and out, distinct
  enough to tell tracks apart while playing. About 820 KB in total.
- `assets/artwork/*.png` - four abstract radial gradients, one per album, generated with `ffmpeg`'s
  `gradients` filter, each in the album's own colour. About 320 KB in total.
- `assets/tab-*.png` - the two tab bar icons for Android, a note and a gear drawn from the Apple
  Symbols font with `ffmpeg`'s `drawtext` (`assets/generate-tabs.sh`). iOS uses SF Symbols instead
  (`music.note.list`, `gearshape.fill`), the same way the wallet example's tab bar does.

All assets together are a little over 1 MB, well inside the budget for an example that ships its
own media.
